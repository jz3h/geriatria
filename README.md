# Hub de recursos — Pós-graduação em Geriatria 2.0 (Afya)

Página de apoio às aulas-pílula do curso. O endereço abaixo está impresso, em código QR,
no último slide de cada aula:

**https://jz3h.github.io/geriatria**

O código impresso nunca muda. O que muda é o conteúdo desta página: para apontar o QR
para outro destino, basta editar `index.html` — por exemplo, trocando a lista de recursos
por um redirecionamento para o servidor onde as ferramentas estiverem rodando:

```html
<meta http-equiv="refresh" content="0; url=https://ENDERECO-DAS-FERRAMENTAS">
```

## Publicação

Settings › Pages › Source: *Deploy from a branch* › Branch `main`, pasta `/ (root)`.

## Conteúdo

- `index.html` — página do hub (lista de recursos, atualizável a qualquer momento).
